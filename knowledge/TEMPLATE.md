# Title: one lesson, as a statement

- **Category:** hardware
- **Summary:** one line: the rule, so the index alone is useful
- **Applies to:** which hardware, firmware, engine category or step (PSP-2000/3000, PPSSPP, the host build, ...)
- **Evidence:** where it was measured: real PSP (model) / PPSSPP (booleans) / PC host / PCSX2 / reasoning
- **Status:** confirmed / partly confirmed / open

## Situation

What you see: the symptom, the log line, the measurement that surprised you.

## Cause

Why it happens, as far as known. Write "Unknown" for what is not known.

## Rule

What to do (and what not to do), in one to five lines.

## Evidence

Numbers with units and where they were measured. No game titles, no addresses of a game's code or data, no paths of
anyone's machine.

## Related

Other notes, skills, documents or source files of this repository.
